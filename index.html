Что именно оптимизировать?

Отключи уже оптимизированные части. Скелет, веса костей и названия анимаций сохраняются.

Загрузи модель, выбери качество и нажми «Создать предпросмотр».

Кнопки «Исходник / Результат» появятся поверх 3D-просмотра. Поворачивай модель и сравнивай детали. Для моделей со скелетом используется осторожное упрощение сетки с учётом влияния костей и UV. Веса выживших вершин не переписываются; проверь суставы в движении перед использованием в игре. Переключатель анимаций убирает только повторы ключей. Если улучшения не нашлось, исходный GLB остаётся точной копией.

Конвертация 3D-моделей

Выбери выходной формат. Для glTF выбирай .gltf + .bin + изображения; для OBJ — .obj + .mtl + изображения. Выбрать несколько файлов можно за один раз. Все операции работают офлайн.

Качество OBJ ZIP для Mixamo

PNG не увеличивается искусственно: если в исходной модели текстура 512 px, выбор 4096 px не добавит ей деталей. Ограничение по числу полигонов снято, но крупные архивы могут долго обрабатываться или не приниматься Mixamo.

GLB → GLB: точная копия без пересжатия, изменения текстур и материалов. Для изменения качества пользуйся вкладкой «Оптимизация». FBX → GLB: выполняется настоящая конвертация. Для Mixamo оставлен FBX 2013 (7.3), однако правильность материалов и анимаций нужно проверить в Mixamo. Компактный PLY убирает нормали, UV и цвета вершин, но не уменьшает число полигонов. BVH (.bvh) можно загрузить и посмотреть движения костей, но перенос на персонажа требует настройки соответствия костей. VRM (.vrm) можно безопасно сохранить без изменений, а полноценный VRM-экспорт из обычного GLB пока не реализован. Обычный OBJ сохраняется единым ZIP: геометрия, MTL и доступные карты текстур. Для Mixamo используй отдельный OBJ-профиль: только цветная Albedo, простой MTL и ZIP — сам архив загружай в Mixamo без распаковки. Для Mixamo можно отдельно выбрать исходную сетку или созданный предпросмотр и размер цветной текстуры. Чем больше исходная модель, тем сложнее Mixamo обработать архив. Для других программ распаковывай OBJ, MTL и PNG в одну папку. Скелет и анимации формат OBJ не поддерживает. Для автоматического риггинга лучше использовать персонажа в T/A-позе без готового скелета.

Профиль Mixamo: сохранится модель с текстурами. Если хочешь расставлять точки для нового скелета, загрузи GLB без скелета в T/A-позе. Наличие уже готового скелета проверим перед экспортом.

Анимации — BVH → персонаж

1. Загрузи GLB / FBX / VRM со скелетом через «Загрузить модель». 2. Выбери BVH. 3. Проверь совпадение костей. 4. Посмотри движение и добавь его в GLB. Исходный файл не меняется.
