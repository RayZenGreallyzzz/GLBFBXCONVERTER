Точные настройки (необязательно)

Загрузи модель, выбери качество и нажми «Создать предпросмотр».

Кнопки «Исходник / Результат» появятся поверх 3D-просмотра. Поворачивай модель и сравнивай детали. Для моделей со скелетом упрощение сетки пока отключено, кости и анимации не меняются.

Конвертация 3D-моделей

Выбери выходной формат. Для glTF выбирай .gltf + .bin + изображения; для OBJ — .obj + .mtl + изображения. Выбрать несколько файлов можно за один раз. Все операции работают офлайн.

GLB → GLB: точная копия без пересжатия, изменения текстур и материалов. Для изменения качества пользуйся вкладкой «Оптимизация». FBX → GLB: выполняется настоящая конвертация. Для Mixamo оставлен FBX 2013 (7.3), однако правильность материалов и анимаций нужно проверить в Mixamo. Компактный PLY убирает нормали, UV и цвета вершин, но не уменьшает число полигонов. Для автоматического риггинга лучше использовать персонажа в T/A-позе без готового скелета.

Профиль Mixamo: сохранится модель с текстурами. Если хочешь расставлять точки для нового скелета, загрузи GLB без скелета в T/A-позе. Наличие уже готового скелета проверим перед экспортом.

Анализ совместимости

Загрузи модель для анализа.

VRM сохраняет специальные метаданные лишь в исходном VRM. OBJ, PLY и STL предназначены прежде всего для статической геометрии. Поддержка USD/USDC и полноценного USDZ с анимациями требует дополнительного движка. Структурная проверка не заменяет тест в Godot и Mixamo.
